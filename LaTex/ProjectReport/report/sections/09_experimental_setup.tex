(\code{-Wall -Wextra}); reproducing the captured runtimes via CMake
requires \code{-DCMAKE\_CXX\_FLAGS="-O2"}.

\subsection{Reproducibility}

\begin{itemize}
  \item Greedy and Hungarian are inherently deterministic (tie-break
        rules are stable).
  \item Pareto sweep deterministically varies the FNV-1a tie hash
        by integer seed (\code{kPolicySeedCount = 5}).
  \item Adversarial bench builds scenarios in C++ memory; no JSON;
        byte-exact across hosts.
  \item \code{Results.md} + six \code{bench\_results\_*.txt} files
        pin the captured numbers to the 2026-04-29 run.
\end{itemize}
