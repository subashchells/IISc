\subsection{What changes during scheduling}

\begin{itemize}
  \item Each worker's ``next free at'' time is advanced.
  \item Each worker's shift remaining decreases (can go negative
        $\Rightarrow$ overtime).
  \item Each task is marked DONE and stamped with its assigned
        worker.
\end{itemize}

\noindent
The bench layer makes a deep copy of all this state before every
cell, since the engine mutates it in place.

\subsection{How runs stay deterministic}

\begin{itemize}
  \item Hash-map iteration is reproducible (we sort).
  \item Tied priorities resolve via a seeded hash of the task ID.
  \item The matcher's tie-break (smaller column wins) is stable.
\end{itemize}
