\section{Evaluation Metrics}
\label{sec:metrics}

\subsection{What each stakeholder cares about}

\begin{itemize}
  \item \textbf{Clinician.}\;
        How long until each acuity tier finishes care.
  \item \textbf{Administrator.}\;
        Total schedule length and total overtime.
  \item \textbf{Workers.}\;
        Whether the load is shared evenly within a role.
  \item \textbf{Engineer.}\;
        Wall-clock and how often Hungarian had to defer a task.
\end{itemize}

\subsection{Why these specific definitions}

\begin{itemize}
  \item Patients with no scheduled tasks are excluded from
        per-acuity averages --- counting them as zero would falsely
        improve the mean.
  \item ``Within-role'' spread, not overall spread:
        a nurse and a resident don't do the same work, so their
        load difference is structural and unmovable. Within-role
        spread is what a matcher can actually rebalance.
  \item All Pareto axes are framed as ``smaller is better'' so the
        dominance check is one rule (componentwise $\leq$).
  \item 90\textsuperscript{th}\,percentile and worst-case are
        reported alongside the mean --- a single bad-luck patient
        gets lost in averages.
\end{itemize}
