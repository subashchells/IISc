\section{Objective:}
This project aims to design and build an algorithm-based ward task 
management system that optimally schedules tasks to healthcare workers 
based on their skills, availability, and priority.
This project focuses specifically on the cardiology ward,
as a scoped implementation for a course project.
The expected outcome is a demonstrably more optimised task allocation 
system that can be used in hospitals to improve the quality of care, 
minimize task turnaround time, and reduce the workload of healthcare workers.
