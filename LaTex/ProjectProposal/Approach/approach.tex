\section{Approach:}
The system will be built using Kahn's Topological Sort and greedy algorithms. Kahn's algorithm will be used to get the  correct execution order (e.g., Troponin + ECHO $\rightarrow$ Stress Test).Greedy algorithms for priority mapping(e.g., suspected MI $\rightarrow$ stable chest pain $\rightarrow$ routine follow-up).
The system will be improved iteratively after doing clinical validation and sanity check.Explore the possibility of using other algorithms and data structures.Perform benchmarking against the standard pen and paper method.
